# .github

Shared settings for all of [@p32929](https://github.com/p32929)'s repositories. GitHub uses the files here for any of my repos that doesn't have its own, so I only have to keep one copy.

## What is inside

| File | What it does |
|---|---|
| [`FUNDING.yml`](FUNDING.yml) | Shows the **Sponsor** button (Buy Me a Coffee) on repos that don't have their own funding file |

This repo has no code. It only holds the shared settings GitHub looks for.
